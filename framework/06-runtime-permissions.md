# Runtime Permissions

## Level A

Safe automatic actions.

Examples:

- compile
- tests
- read-only inspection

---

## Level B

Ask once per session.

Examples:

- commits
- documentation updates
- local artifact generation

---

## Level C

Always ask.

Examples:

- push
- migrations
- destructive actions

---

## Level D

Blocked.

Examples:

- force push
- production destructive actions
